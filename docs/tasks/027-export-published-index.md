# 027 — Выгрузка опубликованного индекса

Добавить `export_index(path)` для выгрузки готового корня или подпапки через
существующий механизм snapshot jobs, manifest и ZIP.

- Возраст индекса, наследуемые правила игнорирования и штатные исключения
  не блокируют выгрузку. Новая индексация и прямой обход не запускаются.
- Используются текущий PathGuard и проверка пригодности поколения. Манифест
  сообщает версию, интервал наблюдения и число исключённых записей области.
  `complete` описывает полноту выгрузки опубликованных записей.
- Формат выбирает текущая настройка snapshot. Срок хранения и лимиты
  артефактов общие. Повторный запрос использует готовый экспорт того же
  поколения, пока артефакты доступны.
- Сохранить контракт обычного `snapshot`. Действующий сервис и туннель
  обслуживаются отдельно.
