## Контекст и границы

Клиенты работают с общими SMB-корнями и одинаковыми правами. FileMCP
по запросу сохраняет метаданные в SQLite на локальном диске сервера, в
его scratch. Процесс открывает существующую БД при старте или создаёт
пустую. Встроенный кэш всего каталога, расписание пересборки, индексация
содержимого и пользовательские ACL находятся за границей задачи.
Чтение оригиналов остаётся через действующие guarded tools.

## Приёмка

- [x] `list_roots` показывает пригодность и дату индекса по каждому корню.
      `index_root` ставит работу в общую последовательную очередь. Для
      повторного запроса активного корня возвращает `Already requested`.
- [x] Публикация атомарная. Сбой, отмена при останове и неполный обход
      сохраняют предыдущую опубликованную версию. После рестарта можно
      искать и экспортировать сохранённый индекс.
- [x] `search_index` поддерживает ограниченный поиск по именам,
      расширениям, mtime и поддереву. Порядок стабилен, курсор привязан к
      запросу и версии. Точное имя и регистр пути сохраняются.
- [x] `snapshot` сам запрашивает построение индекса при его отсутствии
      и экспортирует совместимую область через прежние job, manifest и ZIP.
      Оба формата сохраняют схему и наблюдённое время. Свежесть, принудительное
      обновление, фильтры, дерево, счётчики и границы доступа проверяются.
- [x] Проверка собранного MCP на синтетических файлах покрывает restart,
      конкуренцию, ошибку обхода, pagination, точные пути Windows, 8.3 при
      поддержке томом, junction и изоляцию scratch. Записаны результаты и skips.

## Work record

Рабочая ветка `codex/023-persistent-file-catalog` от карточки `32aff466`.

- Включение через `FS_CATALOG_ENABLED=1` или portable `catalogEnabled: true`.
  Один процесс владеет `<scratch>/catalog.sqlite`. Хранится метадата полного
  поколения, наблюдённый интервал, точные пути и счётчики подпапок. Индекс и
  экспорт живут независимо. Оригиналы обслуживаются обычными guarded tools.

  Повторный запрос корня получает текущий ID. При смене корня/политики старый
  каталог не используется. Поиск сортирует по точному пути, курсор привязан к
  запросу, версии и текущему процессу.

  несовпадении фильтрации подпапки возможен прямой обход. Обновление запускает
