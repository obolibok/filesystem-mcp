# 025 — SQL для опубликованного каталога

Статус на [центральной доске](../project/status.md).
Ветка `codex/025-catalog-sql`, зависит от исправления 024.

- `query_index(path, sql, params)` принимает один запрос чтения. `files`
  содержит файлы опубликованной версии выбранного корня или подпапки.
  Служебные таблицы, запись, подключение БД и загрузка расширений закрыты.
- Запросы имеют лимиты времени, памяти и результата. Проверяются точный
  `COUNT`, `GROUP BY`, поиск подстроки и изоляция корней и поколений.
- В SQL пути используют `/`. Канонический корень и написание из portable
  config доступны отдельно. Индекс сохраняет время создания из `birthtime`.
  Служебные `scopes` сохраняют поддержку экспорта и счётчиков обхода.
- Чистая БД новой версии создаётся автоматически. Старый файл получает
  понятную ошибку, а его удаление остаётся за оператором.
