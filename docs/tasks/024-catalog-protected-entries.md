# 024 — Защищённые элементы при индексации

Статус на [центральной доске](../project/status.md).

В пилоте 023 полный каталог не публиковался. Guarded-обход на Windows
встретил штатные исключения denylist и системную папку, на которую ОС вернула
`EPERM`. Каталог показывал общий `IO_ERROR` в обоих случаях.

## Приёмка

- Разрешённые записи попадают в индекс рядом со штатными исключениями policy.
  Имена исключённых объектов отсутствуют в индексе.
- Известная Windows-папка `System Volume Information` на первом уровне
  исключается при `PERMISSION_DENIED`. Обычные ошибки доступа, I/O и сбои
  SQLite по-прежнему сохраняют предыдущее опубликованное поколение.
- Snapshot сохраняет контракт для затронутой области, включая счётчики и
  неполноту живого обхода. У отказа индексации виден этап и исходный код.
- Проверка на синтетических данных. Пилотная служба и туннель остаются в работе.
