   текущий PID сервера после первого обращения; не принимать одну готовность

3. Чат B: тот же path без переданного jobId/ключа; completed_reuse, тот же job и

   возвращает управление; B немедленно вызывает тот же path с maxAgeMs=0 без key.

5. Завершение, получение artifacts, forced retry/new scan и проверка изменений
