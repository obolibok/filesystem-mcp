## R4 P2: globstar из brace alternative ограничивается raw slash count

Место: `src/core/glob.ts:479–482`, затем `537–543` и `574` на reviewed head.

Fixture: a/file.txt и a/a/file.txt, содержимое token. Реальные MCP find_files
и search_text, explicit root, includeHidden=false, includeIgnored=true,
maxDepth=2; для search_text searchPattern=token. Limit/pageSize по умолчанию.

| Pattern               | Принятый runtime после 010 | Reviewed 011                       |
| --------------------- | -------------------------- | ---------------------------------- |
| `**/file.txt`         | Оба файла                  | Оба файла                          |
| `{*,x}*/file.txt`     | Оба файла                  | Только a/file.txt, truncated=false |
| `{*,x}{*,y}/file.txt` | Оба файла                  | Только a/file.txt, truncated=false |

У обоих инструментов isError=false. Без maxDepth (default=100) результат
тот же: вложенный файл потерян. Дополнительный пример `{*,x}*/b.txt` с единственным
Wanted/nested/b.txt даёт пустой успешный ответ вместо файла.

Причина: в raw pattern нет буквального **, поэтому patternDepth равен числу
slash, здесь 1. Это уменьшает общий maxDepth до 1. Lazy expansion затем правильно
получает `**/file.txt` и вычисляет branch depth=100, но Math.min(maxDepth, depth)
снова обрезает его до 1; walker тоже получает общий bound maxDepth+1. В итоге
запрошенный пользователем maxDepth=2/100 не помогает. Это семантика уже
поддерживаемого шаблона, а не предложение нового glob capability.

Для обоих tools независимо проверены maxDepth=0/1/2: при 0 всё пусто, при 1
только a/file.txt; при 2 прямой ** даёт оба файла, brace-produced ** — только
первый. Baseline использовал фактический source planning main `9d2a792e`,
чей runtime после 010 менялся только документами. Начальная дополнительная
выборка: 7 patterns × 2 tools; затем depth matrix: 3 × 3 × 2 tools.

Исправить общий bound с учётом семантики раскрытых ветвей, сохранив lazy
обработку и реальный пользовательский depth cutoff. Консервативный общий bound
допустим, если branch-specific pruning остаётся точным; не нужно ради этого
материализовать все alternatives. Добавить оба MCP regressions для single- и
adjacent-choice globstar, maxDepth=0/1/2/default, реальные opens/ignore reads,
limit cutoff и конечные branches без globstar. Предыдущие R1–R3 и отмена остаются
обязательными. Исправление — в существующей ветке исполнителя, без изменения scope.
