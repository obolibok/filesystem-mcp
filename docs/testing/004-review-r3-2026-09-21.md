CRC/counter/DeflateRaw/counter intermediates. Он устанавливает finished до destroy
и дожидается закрытия всей цепочки при остановке. Instrumentation ограничена
собственными экземплярами, глобальные stream prototypes runtime не меняет.

Независимые synthetic probes на точном head:

- Восемь последовательных oversized jobs: original 8 MiB, ZIP/delivery cap 64 KiB.
  Все восемь compressors уже destroyed/closed, native handle отсутствует до GC.
- Восемь originals по 64 KiB со split: четыре части, 105 наблюдаемых streams,
  включая 18 compressors; все закрыты.
- Source error посреди второго файла, сразу после создания его lazy compressor
  и до запуска compressor: failed, без partial artifacts; цепочки закрыты.
- Cancel при compression второго файла: cancelled, partial cleanup PASS.
- После каждого сценария следующая job на том же manager завершилась успешно.

Новая regression удерживает сильные ссылки на восемь compressors и проверяет
closed/destroyed без принудительного GC. Дополнительный probe использовал WeakRef.
Признак закрытия — состояние stream и отсутствие native handle: async_hooks destroy
для JS-обёртки ZLIB может приходить лишь при GC и сам по себе не означает открытый
компрессор. В предыдущем head native handle оставался; теперь он закрывается явно.

## R4 — резерв ZIP при partial write: PASS

zipReservedBytes отделён от полностью записанных zipBytes. При ошибке записи
сохраняется резерв всего текущего chunk, пока partial не удалён. Unlink failure
оставляет консервативный резерв, а не неучтённые bytes на диске.

Независимый probe перехватывал реальный FileHandle.write, без нового test hook:

1. Первая короткая запись сохраняет 8192 B; следующая запись получает EACCES.
   Удаление ZIP partial также получает EACCES.
2. Job failed, artifacts=0; partial занимает 8235 B, tempBytes=16427 B.
   Резерв больше фактического остатка, недоучёта нет.
3. При scratch quota 1100000 B следующая job с original 1092000 B получает
   Artifact scratch quota exceeded.
4. После TTL cleanup partial отсутствует. Тот же workload завершается completed,
   complete=true, tempBytes=0; ZIP 1240 B и manifest 2187 B.

Regression дополнительно проверяет отказ следующей job под квотой и восстановление
после очистки. Fatal storage policy и source authorization не изменены.
