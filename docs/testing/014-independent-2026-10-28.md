## Завтрашний протокол

На сервере установить новую папку отдельно от рабочей, перенести tunnelId и запустить
Check/Start согласно HTML-инструкции. Для каждого из трёх roots отдельно выполнить
`snapshot(forceRefresh=true)` и затем `snapshot_tree(forceRefresh=true)` с одинаковыми
includeHidden/includeIgnored и новым уникальным ключом для каждого из шести jobs.
Для потерянного ответа повторять тот же ключ. Вызовы делать попарно и
последовательно, сохранить конечный status каждого job и все manifest/parts.

Измерить отдельно серверный `elapsedMs`, ожидание каждого фонового job, выдачу
manifest, доставку всех частей в локальную библиотеку, их размеры, SHA-256/CRC,
распаковку, восстановление файловых путей, directories/U/complete и поиск по
одинаковым точному относительному пути, части basename и расширению. Сравнение путей,
размера и LastWriteTime имеет смысл при неизменном источнике; snapshots неатомарны.
В Git записать только обезличенные агрегаты. Не коммитить реальные имена/пути файлов,
документы, host/volume идентификаторы, ключи или архивы.
