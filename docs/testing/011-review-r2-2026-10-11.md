## R3 P2: brace alternatives обходят исправления spelling

Место на reviewed head: `src/core/glob.ts:253–258`, `280–282`, `317`, `348`;
соединение normalization/resolution с matcher — `472–481`.

Создать synthetic root с Wanted/a.txt и Wanted/nested/b.txt, содержимое token.
Каталог Else не создавать. Вызвать find_files и search_text с explicit path,
includeHidden=false, includeIgnored=true, default depth/limit; для search_text
searchPattern=token. Меняется только pattern:

| Pattern                   | Принятый runtime до 011 | Reviewed 011                          |
| ------------------------- | ----------------------- | ------------------------------------- |
| `{Wanted,Else}/*.txt`     | Wanted/a.txt            | Wanted/a.txt                          |
| `{wanted,Else}/*.txt`     | wanted/a.txt            | Пусто; isError=false, truncated=false |
| `{./Wanted,./Else}/*.txt` | Wanted/a.txt            | Пусто; isError=false, truncated=false |

Таблица воспроизведена для **обоих** MCP tools. Независимая выборка из 15
шаблонов дала 30 сравнений; различия — эти два шаблона у каждого инструмента.
Контроли включали brace alternatives с slash, finite wildcard и extglob.
Принятый runtime текущего planning main `d422b61c` после 010 менялся только
документами; для сравнения использовался его фактический source через tsx.

Причина: `{...}` сразу считается magic, поэтому initial literal resolution
получает пустой prefix. Matcher работает с агрегатным выражением вместо
разрешения literal ветвей так, как это делает native fs.glob. Finite fallback
снова передаёт brace segment в matchesGlob. Dot normalization удаляет только
целые slash-separated dot segments, но не начальное ./ внутри alternatives.
В результате те же spelling cases, исправленные для простого prefix, остаются
неисправными при использовании ранее поддерживаемых альтернатив.

Сохранить семантику поддерживаемых brace patterns при нормализации, guarded
literal lookup и pruning. Не заменять это общим nocase, полным обходом с
последующей фильтрацией или необоснованным отказом от поддерживаемого синтаксиса.
Проверить оба MCP tools, dot/case alternatives и controls с совпадающим регистром;
на case-sensitive FS case должен следовать native semantics. Добавить проверки
реальных depth/limit opens и отмены для затронутого пути. Если выбранное решение
раскрывает alternatives, ограничить его работу и сохранить проверки отмены.
