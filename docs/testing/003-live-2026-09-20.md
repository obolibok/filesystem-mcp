После малого PASS созданы два неизменяемых synthetic набора. Все файлы нулевые,
mtime `2026-09-20T12:00:00.000Z`; в каждом есть три контрольных имени:
`control,Größe-Антенна.txt`, `control-no-extension-Ω`, `control-plain.txt`.
Остальные имена и длинные вложенные пути генерируются детерминированно.
Это проверка объёма и доставки; она не моделирует скорость обхода миллионов
производственных файлов или прежний обход длительностью 20–30 минут.

Новый локальный preflight на той же сборке использует отдельный scratch и
реальные MCP snapshot/job_status/get_artifact. Полученные bytes независимо
проверены Python stdlib: SHA-256, ZIP CRC, строгий UTF-8/CSV, schema, все поля,
количество строк, отсутствие дублей и полное множество ожидаемых путей.

| Набор / часть | Строк | Raw CSV, B |  ZIP, B | Base64, B |
| ------------- | ----: | ---------: | ------: | --------: |
| main / 1      |  9552 |   47181985 | 5530035 |   7373380 |
| main / 2      |  9549 |   47181666 | 5529811 |   7373084 |
| main / 3      |  1910 |    9437367 | 1106443 |   1475260 |
| upper / 1     | 13852 |   47183919 | 7802264 |  10403020 |

- main: 21011 файлов, submit 26 ms, terminal около 35,9 s, manifest 2458 B;
- upper: 13852 файла, submit 6 ms, terminal около 21,3 s, manifest 1866 B;
- обе jobs `complete=true`, errors 0; независимый verifier — PASS.

Base64 length не является полным измеренным wire size. Первые запуски verifier
прошли assertions, но завершились ошибкой cp1252 при выводе Unicode в консоль;
повтор с `python -X utf8` завершился exit 0 для обоих наборов.

Эталон множества путей, независимо совпавший в Node и Python:

```text
main:  a26d63329b5aaa6526fb7e71b3b1896d4f7937576379c59f28d8b45e75cce5b2
upper: cd7b0245325270b816ac7c75111c6eaae61054ce31ac9f3519d66de95f4b9f3c
```

Алгоритм: для каждого `RelativePath` взять бинарный SHA-256 от UTF-8 строки
`RelativePath + LF`, отсортировать 32-байтовые digest побайтово, склеить и вычислить
SHA-256. Проверять уникальность отдельно; не нормализовать пути и Unicode.
Эталон вычислен из generated fixture, а не из серверного manifest.

Результаты этого раздела — **LOCAL_ONLY_NOT_CHATGPT**. Целевые main и upper PASS
записаны отдельно выше с источниками evidence.
