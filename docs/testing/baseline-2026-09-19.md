# Исходная проверка: 2026-09-19

Историческая запись. Исходники: `4f2625bf`, version 2.3.0. Среда: Windows,
Node `v24.15.0`, npm `11.12.1`. До анализа tracked tree был чистым. Зависимости
установлены через `npm ci` по существующему lockfile. Runtime при анализе не менялся.

Полный `npm run check` не прошёл, потому что остановился на Prettier. Последующие
Knip/tests запускались отдельно. Семь skips: два POSIX-only сценария и пять
сценариев с недоступным созданием file symlink; это не полное покрытие этих веток
на Windows. Доступные junction-сценарии выполнялись.

Первый test run в sandbox завершился до загрузки suites: `tsx` получил
`uv_os_get_passwd` error. В разрешённом запуске вне sandbox tests прошли. Ошибка
инструментального окружения отделена от дефектов сервера.

Prettier API проверил 96 eligible tracked files. Все 96 не прошли на исходном
CRLF и прошли после CRLF → LF только в памяти; других format changes не было.
Причина — `core.autocrlf=true`, отсутствие `.gitattributes`, default LF в Prettier.
Глобальный Git config не менялся.

## Воспроизведённые дефекты

1. UTF-16LE с BOM: `read` сообщил success/text, но вернул NUL и replacement chars;
   `search_text` не нашёл реально присутствующий ASCII-маркер. По коду аналогичная
   политика затрагивает BE; обе byte orders должны войти в regression cases.
2. Binary `.bin`: `read` вернул `INVALID_INPUT: Binary file detected`, но
   directory `search_text` нашёл внутри ASCII-маркер и вернул бинарный мусор.
3. Descriptions `find_files` и `search_text` обещают first root, в то время как
   `resolvePathOrRoot` требует explicit path при нескольких roots (проверено по коду).

При подготовке карточки 001 выявлен связанный статический риск: `readRaw()`
выбирает text/blob через MIME kind, известное `.txt` имеет приоритет над sample,
и `resources/read` затем декодирует такой контент в UTF-8. Поэтому изменение только
`isBinarySample()` не гарантирует сохранения UTF-16/binary originals. Это вывод
из кода; отдельное runtime воспроизведение включено в acceptance задачи 001.

Минимальные Buffer fixtures и MCP arguments находятся в
[самодостаточной карточке 001](../tasks/001-baseline-defects.md). Новому checkout
не требуются исходные ignored probe scripts, их логи или пользовательский PDF.

## Что доказано и что ещё нет

Локальный клиент получил оригинальные байты небольшого ZIP, состоящего из TXT и
binary. Read-only публиковал ровно семь tools; вызов `create` был отвергнут, файл
не появился. Дочерние процессы smoke завершены.

Это не проверка доставки в вычислительную среду ChatGPT, не нагрузочный тест
миллионов файлов, не испытание сетевого UNC deployment и не повторение
производственного исследования Daum/Inoplacer. Реальные документы использовались
только как предоставленный контекст требований; filesystem tests были synthetic.

После исправления сохранять эту запись исторической. Новые counts, contracts и
результаты записать в Work record задачи и обновить reference, не заменяя baseline
новыми показателями задним числом.
