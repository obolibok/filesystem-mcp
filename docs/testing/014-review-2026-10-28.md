## Проверка контракта

Стабильный tool получает прежние normalized inputs/fingerprints без layout.
Только tree добавляет discriminator tree-depth-v1. Оба используют общий submit,
walker/writer/ZIP/manager/storage; нет второго job manager, БД или in-memory tree.
Feature flag не входит в legacy policy/config identity. Default registry 19/13;
opt-in 20/14. Portable boolean валидируется, inherited env очищается.

Первый CSV record содержит actual sourceRoot, далее header и D/F/C/U. Код
использует числовую глубину, basename, RFC 4180/UTF-8/CRLF; context предков
восстанавливает путь в каждой части. Служебные записи учтены в лимитах/счётчиках,
но не считаются файлами/новыми папками. Пустые dirs сохраняются, child faults
маркируются U/complete=false; root/policy/storage failures остаются fatal.
Streaming guard/policy/ignore/no-follow/scratch и provenance сохранены.

Manifest tree имеет отдельные schema/version/layout; optional status/counters
не переписывают старые jobs/artifacts. Layout mismatch, невозможные root/context
budgets и caps дают явный failure, без бесконечного разбиения. Independent reader
не импортирует production encoder/path helpers; CRC/SHA отрицательные controls
и exact path expectations в tests проверены.
